# myarchinstall

日本語環境に最適化された、対話型の Arch Linux インストーラースクリプトです。
複雑なコマンドを手動で打ち込むことなく、質問に答えていくだけで、すぐに使える状態の Arch Linux を構築できます。

## 特徴

- **対話形式**: 画面の指示に従って番号やテキストを入力するだけでセットアップが進行します。
- **完璧な日本語環境**: ロケール、タイムゾーン、日本語フォント、日本語入力 (fcitx5-mozc) が自動で適切に設定されます。
- **多彩なデスクトップ環境に対応**: 
  - メジャーな環境: GNOME, KDE Plasma, Xfce, Budgie
  - 次世代 Wayland タイル型: Hyprland, Niri, COSMIC
- **自動最適化**: GPU ドライバーの自動判別、ZRAM の有効化、並列ダウンロードの有効化などを自動で行います。
- **Wayland への対応**: Hyprland や Niri といった最新の環境でも、Waybar、クリップボード、自動サスペンド (`swayidle`) などの周辺ツールが自動設定されます。

## 使い方

Arch Linux のインストールメディア (Live USB) から起動し、インターネットに接続した状態で以下の手順を実行します。

1. スクリプトを実行します。
   ```bash
   sudo bash install.sh
   ```
2. 画面の指示に従い、以下の項目を選択・入力します。
   - インストール先ディスク
   - パーティション構成 (自動 / 手動)
   - デスクトップ環境
   - ホスト名、ユーザー名、パスワード
   - GPU ドライバー (NVIDIA, AMD, Intel, または自動判別)
   - 追加パッケージ (任意)
3. インストールが自動で進行します。完了後、再起動すると選択したデスクトップ環境が立ち上がります。

## ドライラン（テスト実行）

実際にディスクに変更を加えず、どのような処理が行われるかテストしたい場合は `--dry-run` オプションを使用します。

```bash
sudo bash install.sh --dry-run
```

## 注意事項

- 本スクリプトを使用すると、選択したディスクの**全データが消去**されます。実行前に必ずディスクの選択を確認してください。
- Windows とのデュアルブートを構成する場合は、事前に Windows 側のディスクの空き容量を確保しておくか、別のディスクを用意してください。
